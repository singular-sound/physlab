示波器 · 上课小抄

忘了怎么做就从头往下看。旋钮名称就是 GOS-630FC 面板上印的英文。整个实验只有 3 种操作：看波形数格子、X-Y 模式拍李萨如图形、ADD 模式拍「拍」。

进门前确认：预习测试题已经通过（没通过刷脸签不了到）；带了预习报告和教材；手机有电，要拍很多照片。

操作一：看波形、数格子

对应教材实验内容 1～5，填表 1。

步骤

  1. 开机：按 POWER，等一会儿，屏上出现一条横线。
    • 没有线：调大 INTEN，把 POSITION 往回拧，确认 TRIGGER MODE 在 AUTO。
    • 线太粗：调 FOCUS。
  2. 信号源出正弦波 1 kHz，确认 output on 的灯亮着（不亮就没有输出），用线接到 CH1。各型号怎么设频率见下面「信号源怎么设频率」。
  3. 把波形调稳：先拧 TIME/DIV，屏上留 2～3 个完整的波；再拧 LEVEL，直到波形停住。
  4. 把波形调大：拧 VOLTS/DIV，让波形尽量高，但别超出屏幕。
  5. 数格子、记数：
    • 用上下 POSITION 把波谷压到一条横格线上。
    • 波峰到波谷几格记 a，小屏上的 VOLTS/DIV 读数记 b。
    • c 个完整周期占几格记 d，小屏上的 TIME/DIV 读数记 e。
    • 拍照：大屏和小液晶屏拍进同一张。
  6. 再测 3 组：换 100 Hz、换三角波，按第 3～5 步重做，凑齐表 1 的 4 行。
  7. 标准方波修正：
    • 档位都别动，把输入线从信号源拔下来，插到示波器的 CAL 端子上。
    • 看一眼 CAL 旁边印的是 1V 还是 2V，拍下来。
    • 方波峰-峰值几格记 f，一个周期几格记 g。
  8. 测直流分量（三角波、正弦波各一次）：
    • 拨 GND：屏上变成一条线，用 POSITION 对到中间那条格线，这是零线。
    • 拨 AC：记波谷在第几格。
    • 拨 DC：再记波谷在第几格。
    • 两次位置差 × VOLTS/DIV = 直流分量。

操作二：X-Y 模式，李萨如图形

对应实验内容 6～7，填表 2、表 3。

  1. 两路信号分别接 CH1、CH2：一路是频率已知的信号源，一路当待测信号。YB1602 那台频率不太稳，适合当待测信号。
  2. VERT MODE 拨 DUAL，确认两路波形都有。
  3. TIME/DIV 逆时针拧到头，进入 X-Y 模式（CH1 是 X，CH2 是 Y）。
  4. 测频率：慢慢拧已知信号源的频率，依次调出 1:1、2:3、1:3。每种拍一张照片，记下当时的已知频率。
    • 图形慢慢转、变形是正常的，等它转成闭合、凸包清楚的样子再拍。
  5. 测相位差：两路设成同一频率，屏上出现椭圆，拍照。

切点数和椭圆的 a、b 可以课后对着照片数，现场只管拍清楚。

操作三：ADD 模式，拍频法

对应实验内容 8，填表 4。

  1. 把 TIME/DIV 拧回来，退出 X-Y 模式。待测信号接 CH1，可调的标准信号接 CH2。
  2. VERT MODE 拨 CH1：把待测信号调稳，从屏上估一下它的频率。
  3. VERT MODE 拨 CH2：把标准信号的频率和大小都调到和待测信号差不多。
  4. VERT MODE 拨 ADD，确认 CH2 INV 没按下。调 TIME/DIV，再慢慢微调标准信号频率，直到出现稳定的「拍」：外轮廓一鼓一缩，像一串橄榄。
  5. 记一个拍的长度 X1（格）、标准频率 f1、TIME/DIV 读数。
  6. 稍微改一下标准频率，等出现另一个稳定的拍，记 X2、f2、TIME/DIV 读数。
  7. 拍照：CH1、CH2、ADD 三种显示各一张。
信号源怎么设频率（三种型号）

SDF-1003：设 100 Hz 就依次按 1 0 0 Shift 0（Hz）。连续调用左下的 FREQUENCY 旋钮，Shift+4/5 换调的是哪一位。没输出就看右侧 output on 的灯亮没亮。

YB3020：按功能区的「频率」，输数字，再按屏幕下的蓝色按钮选单位。连续调用右上的旋钮，左右箭头换位。

YB1602：先选档位（比如 200Hz 档），再拧「粗调」「细调」。它的频率不太稳，适合当待测信号。
